# 퀀트 트레이딩 시스템

S&P 500 전체 종목을 자동으로 스캔하고, 핫 종목을 감지하며, Interactive Brokers(IB)를 통해 자동 매매하는 퀀트 트레이딩 시스템입니다.

## 핵심 기능

### 1. 자동 종목 스캐너
- S&P 500, NASDAQ-100, S&P 400에서 **500개 이상의 종목**을 실시간 모니터링
- **거래량 이상 감지** — 평소보다 2배 이상 거래량이 급증한 종목 포착
- **Reddit 소셜 분석** — r/wallstreetbets, r/stocks에서 화제되는 종목 추적
- **SEC 내부자 매수** — 임원들이 자사주를 매입하는 종목 감지
- **공매도 스퀴즈** — 공매도 비율이 높은데 가격이 오르는 종목 발굴

### 2. 매매 전략
| 전략 | 설명 |
|---|---|
| **공격형 모멘텀** | 다중 시간프레임(5일/10일/21일) 모멘텀 + 돌파 감지 + 거래량 확인 |
| **클래식 모멘텀** | 126일 수익률 기반, 상위 5개 종목 |
| **평균 회귀** | RSI 기반 — 과매도 종목 매수 |
| **섹터 로테이션** | 강한 섹터 ETF에 집중, 하락장에서 채권/금으로 전환 |
| **복합 전략** | 모멘텀 40% + 평균회귀 30% + 섹터 30% 분산 투자 |

### 3. 리스크 관리
| 안전장치 | 조건 | 동작 |
|---|---|---|
| 손절매 | 개별 종목 -5% | 즉시 매도 |
| 익절매 | 개별 종목 +10% | 이익 실현 |
| 일일 손실 한도 | 당일 계좌 -5% | 당일 매매 중단 |
| 킬 스위치 | 최고점 대비 -20% | 전 종목 청산 |
| 포지션 한도 | 단일 종목 35% 초과 | 매수 차단 |

### 4. 백테스트 엔진
- 슬리피지 및 수수료 반영
- SPY, QQQ, 60/40 포트폴리오 등 벤치마크 비교
- 96가지 파라미터 조합 자동 테스트
- 수익곡선 및 낙폭 차트 자동 생성

## 작동 방식

```
15분마다 (시장 개장 중):
│
├── 리스크 체크
│   ├── 일일 손익 확인 (-5% 시 매매 중단)
│   └── 킬 스위치 확인 (-20% 시 전량 청산)
│
├── 보유 종목 관리
│   ├── 손절가 도달 → 매도
│   └── 목표가 도달 → 매도
│
├── 핫 종목 스캔 (매 시간)
│   ├── 비정상 거래량 감지
│   ├── Reddit 트렌딩 종목
│   └── SEC 내부자 매수 공시
│
├── 매매 신호 생성
│   ├── 다중 시간프레임 모멘텀
│   ├── 신고가 돌파 감지
│   ├── 거래량 확인
│   └── 핫 종목 가산점
│
└── 자동 주문 실행 (Interactive Brokers)
```

## 백테스트 성과 (2019-2025)

| 전략 | 연평균수익률 | 샤프비율 | 최대낙폭 |
|---|---|---|---|
| 공격형 모멘텀 | 74.9% | 1.44 | -47.3% |
| 클래식 모멘텀 | 46.9% | 1.20 | -40.0% |
| 모멘텀 + 추세필터 | 30.1% | 0.95 | -32.1% |
| S&P 500 (벤치마크) | 17.3% | 0.91 | -33.7% |

> 백테스트 결과는 생존편향(survivorship bias)이 포함되어 있으며, 실제 수익률과 다를 수 있습니다.

## 실행 방법

```bash
# 환경 설정
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# IB Gateway 또는 TWS 실행 (모의투자 계좌, API 활성화)
# .env 에 IB_HOST / IB_PAPER_PORT / IB_LIVE_PORT / IB_CLIENT_ID / BROKER_MODE 설정

# 데이 트레이더 실행 (모의투자)
python live/run.py --paper

# 매매 시뮬레이션 (실제 주문 없음)
python live/run.py --dry-run

# 계좌 상태 확인
python live/run.py --status

# 핫 종목 스캔
python live/scan.py --full
```

## 기술 스택

- **Python 3.11+**
- **데이터:** yfinance, pandas, numpy
- **시각화:** matplotlib, plotly
- **증권사 API:** Interactive Brokers, ib_async (모의투자 → 실전)
- **종목 소싱:** Wikipedia (S&P 500/NASDAQ-100/S&P 400 구성종목)
- **소셜 분석:** Reddit JSON API, SEC EDGAR RSS
